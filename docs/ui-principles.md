# RENTORA UI PRINCIPLES

# CORE UX PHILOSOPHY

Rentora must feel:

* calm
* modern
* operational
* fast
* enterprise-grade
* cognitively efficient

The platform should NEVER feel:

* cluttered
* noisy
* ERP-heavy
* dashboard chaotic
* operationally exhausting

---

# PRIMARY UX MODEL

The platform follows:

Overview
→ Drilldown
→ Deep operational detail

Primary surfaces must remain:

* simple
* focused
* actionable

Deep information appears only through:

* drilldowns
* secondary views
* contextual navigation

---

# EXECUTIVE VS OPERATIONAL SURFACES

## Executive Surfaces

Purpose:

* summarize
* monitor
* identify exposure
* surface intelligence

Should contain:

* KPIs
* summaries
* exposure metrics
* operational health
* trends

Should NOT contain:

* dense operational tables
* excessive actions
* processing complexity

---

## Operational Surfaces

Purpose:

* execute workflows
* process transactions
* resolve operational tasks

Should contain:

* focused actions
* operational queues
* approvals
* workflow tools

Should NOT contain:

* excessive analytics
* dashboard overload
* unnecessary widgets

---

# IMPORT WORKSPACE PRINCIPLES

Import/reconciliation pages must optimize for:

* speed
* throughput
* clarity
* workflow momentum

The import workspace should:

* upload
* reconcile
* review
* approve
* escalate
* post

ONLY.

Avoid:

* excessive analytics
* operational dashboards
* activity feeds
* deep audit surfaces
* unrelated KPIs

---

# INFORMATION DENSITY RULES

## SHOW FIRST

* status
* queue
* confidence
* exposure
* next action
* operational summaries

## HIDE UNTIL DRILLDOWN

* audit trails
* deep metadata
* AI reasoning
* system history
* advanced analytics
* detailed operational intelligence

---

# ACTION DESIGN PRINCIPLES

Operational actions should:

* remain discoverable
* remain lightweight
* avoid duplication
* avoid clutter

The platform should avoid:

* excessive buttons
* duplicate actions
* conflicting workflows
* hidden capabilities

---

# TABLE DESIGN PRINCIPLES

Tables should prioritize:

* scan speed
* operational readability
* low cognitive load

Avoid:

* too many columns
* excessive badges
* excessive colors
* nested actions

---

# COLOR PHILOSOPHY

Colors communicate:

* operational state
* urgency
* governance
* confidence

Colors should remain:

* subtle
* premium
* restrained

Avoid:

* excessive saturation
* loud enterprise styling
* aggressive warning overload

---

# ENTERPRISE INTERACTION PRINCIPLES

The platform should feel:

* intelligent
* responsive
* operationally fluid

Avoid:

* unnecessary page changes
* excessive modals
* workflow interruption
* navigation fragmentation

Prefer:

* contextual drilldowns
* inline operational flows
* workspace continuity

---

# OPERATIONAL SPEED PRINCIPLES

Every interaction should reduce:

* clicks
* scanning effort
* operator fatigue
* workflow interruption

High-frequency workflows must feel:

* fast
* intuitive
* predictable

---

# LONG-TERM UX DIRECTION

Future intelligence systems:

* AI reasoning
* predictive analytics
* operational timelines
* executive intelligence

must always preserve:

* calm operational UX
* progressive disclosure
* workflow focus
* cognitive efficiency
